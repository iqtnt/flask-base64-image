# Flask Base64 Image Converter

A simple Flask web application that converts Base64-encoded strings into images.  
Paste your Base64 text, preview the resulting image, and download it with a random filename.

## Features
- Paste Base64 text and render it as an image.
- Download the generated image with a unique random name.
- Responsive and modern UI.
- Written in a single Python file using Flask.

## Requirements
- Python 3.9+
- Flask
